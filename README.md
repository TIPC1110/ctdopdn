## 🌟 Tính Năng & Điểm Nổi Bật

- 🎨 **Giao Diện Tối Giản & Sắc Nét**: Nền Obsidian Dark (#0a0b10), đường viền mảnh (#1e2230), card phẳng, không glow/blob decoration.
- ⚡ **Tương Tác Tối Thiểu**: Scroll spy thanh điều hướng, scroll-to-top button, mobile menu toggle. Không animation reveal thừa.
- 📜 **Hồ Sơ Chứng Chỉ Chuyên Nghiệp**: Tổng hợp chứng chỉ Coursera (Kỹ thuật phần mềm UML/Testing/Design, Web Design for Everybody Capstone), Amazon Generative AI, DeepLearning.AI AI For Everyone.
- 🚀 **Showcase Dự Án Thực Chiến**:
  - 🚌 **CTDOBus (`ctdomap`)**: Bản đồ & điều hành xe buýt Hà Nội trực tiếp qua SSE & giải mã AES-256-CBC.
  - 🔑 **ctdoshopkey**: Hệ thống backend viết bằng PHP & MySQL chuyên quản lý bản quyền số & API Keys.
  - 🧠 **LUCA OS**: AI Agentic Brain đa mô hình & Second Brain.
  - ☁️ **ctdocloud**: Desktop app quản lý cloud storage tích hợp Rclone (Rust).
  - ⚡ **CTDOSHub**: Nền tảng backend API với Hono & Supabase.
- 📬 **Form Liên Hệ AJAX**: Tích hợp Formspree API, gửi dữ liệu không tải lại trang.
- 📱 **Responsive Design**: Hiển thị đầy đủ trên mọi thiết bị.
